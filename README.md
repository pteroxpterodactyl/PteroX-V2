# PteroX V2

PteroX V2 is a frontend theme for Pterodactyl Panel.

## Compatibility

- Pterodactyl Panel: 1.14.x
- Recommended base: 1.14.1
- Node.js and Yarn are required to rebuild the frontend.

## Installation

Run:

    sudo ./install.sh

The installer checks the Pterodactyl version, creates a timestamped backup, installs the PteroX V2 files, builds the frontend, and clears Laravel caches.

## Uninstallation

Run:

    sudo ./uninstall.sh

The uninstaller restores the most recent PteroX backup.

## Important

PteroX V2 is intended for Pterodactyl 1.14.x. Other versions are not guaranteed to work.
