# PteroX V2

PteroX V2 is a modern frontend theme for Pterodactyl Panel, featuring a redesigned dark interface, custom navigation, server management UI, and PteroX branding.

## Compatibility

- **Pterodactyl Panel:** 1.14.x
- **Recommended base:** 1.14.1
- **Node.js and Yarn:** Required to rebuild the frontend.

Other Pterodactyl versions are **not guaranteed to work**.

---

## Installation

The PteroX V2 installer automatically checks the Pterodactyl version, creates a backup, installs the theme files, rebuilds the frontend, and clears Laravel caches.

Run:

```bash
sudo ./install.sh

## Uninstallation

To remove PteroX V2 and restore your previous Pterodactyl files, run:

```bash
sudo ./uninstall.sh
